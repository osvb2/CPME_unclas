RISE MOBILE READING EDITIONS

Open index.html in a web browser. Both reading editions embed their fonts and artwork and work offline. Keep the HTML and document files together for companion links and downloads.

For your existing GitHub Pages website, copy this folder into a directory such as rise. The landing page is index.html and opens the brief edition. No build process, external services, scripts, cookies or tracking are used. Uploading these files to a public website makes their contents public.

The full text preserves the corrected CSB command period 2022–2023. The brief Word, PDF and PNG use the same Latin Modern Roman typeface as the full poster. All text in both Word documents remains editable.
